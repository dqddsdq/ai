도구

AI 팀이 쓸 수 있는 도구예요. 허용 목록에 있는 것만 설치·연결돼요. 키는 이 PC의 .env 에만 저장돼요.

요청 기록
차트

토스 데이터로 그린 차트예요 (AI 가 보는 것과 같은 그림). 1분마다 자동 갱신 · 그림을 누르면 크게 · 자동매매가 가진 종목엔 산 가격·손절·나눠 팔기선이 표시돼요.

자동매매

규칙이 종목을 골라 토스 계좌에서 사고팔아요. 사장님이 직접 산 주식·직접 낸 주문은 안 건드려요. 돈을 계좌 밖으로 옮기는 기능은 없어요 (토스 API 에 출금·이체가 없고, 앱은 지정가 주문·취소만 보내요).

자기 개선

AI 팀의 지시문·설정·코드를 고쳐요. 개발 AI 가 복사본에서 고치고 자동 검사까지 한 뒤, 바뀐 내용을 보여 드려요. [적용]을 눌러야 실제로 바뀌고, 언제든 [되돌리기]로 원상복구돼요. 키·도구 허용 목록·도구 설치 코드는 고칠 수 없어요.
