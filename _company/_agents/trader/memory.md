# 자동매매 팀 메모

## 엔진 현황 (개발 쪽에서 정리 — 코드가 바뀌면 이 부분도 갱신)

**자기 개선**: 자동 개선이 기본으로 켜져 있음. `[[IMPROVE: 무엇을 | 왜]]` 로 제안하면 개발 AI가 고침 → 자체 점검 통과 시 승인 없이 적용 → 코드면 앱 자동 재시작 → 실패하면 자동 되돌림 (하루 최대 6건).
- 고칠 수 있음: autotrade.py · tradelearn.py · picker.py · shadow.py · backtest.py · news.py · chart.py · web.py · 화면 · 지시문 등.
- 잠김: .env · tools.py · tools_catalog.json · toss.py · _shared/autotrade.json (설정은 화면이나 TRADE_SET 으로) · notify.py · improve.py · selftest.py · guard.py · __init__/__main__.
- 텔레그램 알림이 이미 연결돼 있음: 자동 개선의 적용·보류·실패·되돌림, 그리고 체결·정지·규칙 교체·공시 악재·익절 비교. 앱이 다시 켜지기 전에 알림을 다 보냄 (시험 완료).

**계좌 안전장치 (잠긴 toss.py)**: 주문 생성·취소만 가능 (출금·이체 불가). 매수 직전 현금(cashBuyingPower)을 다시 확인해 미수 불가. 봇 장부 기준으로 봇이 산 체결 수량까지만 팔고(`toss.bot_sellable`), 봇이 낸 주문만 취소.

**매수**
- 수수료·세금을 뺀 수익률로 계산 (미장 0.1%씩 · 국장 0.015%씩 + 매도세 0.18%).
- 🔬 탐색 매수: EV는 마이너스인데 비슷한 거래가 5건 미만인 후보 → 하루 explore_per_day(2)번만, 최소 금액으로.
- 🔁 재진입 금지: 손해로 판 종목은 단타 그날, 스윙 3일 동안 다시 안 삼.
- 🎯 확신 집중: 비슷한 거래 20건 이상이고 EV +2% 이상일 때만 한 종목 최대 50% (종목당 최대 한도가 우선).
- 📰 공시 확인 (국장 DART · 미장 SEC): 악재면 안 삼, 나머지 공시는 AI 판단과 주문 이유에 반영. 이유 모르는 급등의 금액 배수(news_unknown_ratio)는 그림자 매매 '공시비교'로 비교 중.

**매도**: ai_take_profit = test (규칙으로 익절하되 'AI였으면?' 유령 비교 → 10건 이상 쌓이고 평균 +0.3%p 이상 나으면 자동으로 on). on 일 때는 안전장치: 최고 +3% → +0.3% 까지 밀리면 무조건 매도.

**실험**: 가상·그림자·백테스트 체결은 현재가 대비 0.1% 불리하게 + 수수료 포함.

**안정성**: 저장 시 '액세스 거부'가 나면 다시 시도하고, 실패해도 매매는 멈추지 않음. 앱은 한 PC에서 하나만 실행. 장 전 실데이터 점검.

**계좌 조회**: 실전에서는 바퀴마다 보유·미체결·현금을 새로 조회 → 입금·출금이 자동 반영됨.
